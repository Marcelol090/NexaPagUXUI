# V3.16 · Continuous liquid pigment + reduced-motion lifecycle
The first full QA on V3.15 passed 79 tests and found 4 problems. Three old tests asserted literal version string 3.11 rather than controller availability. The fourth: if reduced-motion is enabled, `fluidFlight` returns without invoking onStart, leaving an aria-hidden departing card mounted with a duplicate `orbStoryTitle` ID, which mislabels the next inline region. Call onStart even for zero-motion branches and ensure the old card is removed.
Card-to-card motion also should never snap from a rounded rectangle to a circular ghost or abruptly jump between mint/coral/lilac. The controller now begins at a card-shaped superellipse and crossfades the old palette into the destination palette inside the shared shape. No extra framework or dependencies.
