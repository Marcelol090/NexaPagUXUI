# V3.14 · Structural fix to true inline morph
A CI screenshot showed the green income card overlapping the greeting at y=100, even though the overlay backdrop was removed. Root cause: `heroMarkup()` contained `.greeting` **inside `#heroRegion`**. The region was given an explicit animated height, but the greeting's DOM layout still began inside that region, immediately after its absolutely positioned orb/carousel elements, so it sat behind the card. Moved `.greeting` to be a sibling of `#heroRegion` under `#homePage`. The animated height of `#heroRegion` now pushes greeting, weekly orbs, and analytics down naturally. Acceptance test checks bounding rectangles don't overlap, greeting is parented directly to home page, and both 320px and larger widths retain correct layout. No popup or backdrop.
