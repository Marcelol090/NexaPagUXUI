# V3.7 — 16-frame liquid-to-card transition
Implements the supplied 16-frame GIF as a real browser-interactive choreography, not image playback. Each orb expands in the relevant tint (Entradas mint, Saídas coral, Estornos lilac) to its original functional card; a single morph engine supports reverse closing. Declarative keyframes contain trajectory, width, height, superellipse curvature, top jet, ripple amplitude and opacity. Between frames the browser interpolates at display refresh rate. Clip polygon has 64 smooth vertices, replacing hard border-radius-only tweening. Destination card appears beneath the flowing ghost in the final quarter. On reduced-motion devices the card opens without a morph. Original NexaPag UI layout, finance values, carousel MP4 shader, dark/light, five tabs and Android code are unchanged.
